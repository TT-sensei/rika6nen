# 理科ラボ 6

小学6年生理科を、条件を操作して現象を確かめるLABと、知識・実験準備・考察の問題学習で学ぶブラウザ教材です。9単元を収録しています。

## この教材の考え方

6年生では、目に見える結果だけでなく、条件を変えたときに関係がどう変わるかを考えます。

- **シミュレーション**：条件を変える → 現象が変わる → 短い結果を確かめる
- **問題を解く**：知識をつなぐ → 条件と証拠を整理する → 結果から説明する

スタート画面では、シミュレーションと問題学習を切り替えて使えます。問題学習の進み具合、研究ランク、発見図鑑、コレクション報酬はブラウザ内に保存されます。

## 収録単元とLAB

| 単元 | LABで試すこと |
|---|---|
| ものの燃え方と空気 | 空気の通り道、はじめの酸素、容器の大きさを変え、炎の変化を見る |
| 動物のからだのはたらき | 運動の強さ、追いかける物質、食後の養分を変え、呼吸・心拍・血液の流れを見る |
| 植物のからだのはたらき | 光・水・葉の枚数・葉をおおう割合を変え、水の移動、蒸散、でんぷんの目安を見る |
| 生物と環境 | 植物、昆虫、小動物、鳥、水の量を変え、食べる関係の変化を見る |
| 月と太陽 | 月を軌道上で動かし、宇宙から見た位置関係と地球から見える月の形を同時にくらべる |
| 大地のつくりと変化 | 水の速さ、運ばれる土砂、火山灰、地震を変え、たい積や地層の変化を見る |
| てこのはたらき | 支点、左右のおもり、位置を動かし、重さ×距離とつり合いをくらべる |
| 電気の利用 | 電池、器具、スイッチ、ためた電気を変え、光・運動・熱への変換を見る |
| 水溶液の性質 | 水溶液と調べ方を選び、リトマス紙・蒸発・気体・金属の変化をくらべる |

## LABの種類

### てこLAB・月と太陽LAB

この2つは、共通の本格LAB基盤を使います。

- 自由研究と探究ミッションを切り替えられる
- 予想を選んでから条件を操作できる
- 直接操作やアニメーションで現象を確かめられる
- 実験結果を記録し、複数の結果をグラフでくらべられる
- 記録はLABノートとして利用中のブラウザに保存される

### 燃焼・水溶液・電気・植物・人の体・生物と環境・大地LAB

この7つは、共通のコンパクトLAB基盤を使います。

- ボタンやスライダーで条件を変更
- 条件に応じた図・数値・短い説明を即時表示
- 「すぐ試す」プリセット、リセット、時間を進める操作（一部LAB）を用意
- 自由記述や保存を前提にせず、条件変更と結果確認を短時間で繰り返せる

すべての数値や動きは、学習する関係が見えやすくなるように単純化したモデルです。実際の薬品、火、電気器具、生き物の観察では、必ず先生の指示に従ってください。

## 問題学習

問題学習は、単元ごとに次の3段階で進みます。

1. 知識：大事な言葉をつなぐ
2. 実験・観察の準備：条件と証拠を整理する
3. 考察：結果から説明する

- 条件カードや安全に関する問題を収録
- 答え合わせと解説を表示
- 全9単元の中心を確かめる「まとめチェック」
- 進捗、初回正解、間違えたカードなどを localStorage に保存

## 主な機能

- タブレットで操作しやすいレスポンシブUI
- LABの入口を開くまで、LAB本体を読み込まない遅延読み込み
- 選んだLABに必要な共通基盤と単元ファイルだけを読み込む構成
- 研究ランク、発見図鑑、おまけコレクション
- 効果音のオン・オフ設定
- 外部API、APIキー、サーバー、データベース、外部フォントを使用しない構成
- GitHub Pagesでそのまま公開可能
