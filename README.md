# 理科ラボ 6

小学6年生理科を、問題学習と「予想 → 条件操作 → 実験 → 記録 → 比較 → 考察」のシミュレーション型LABで学ぶ、ブラウザ完結型の教材です。

既存の問題・判定・進捗・まとめチェック・発見図鑑は残したまま、現象を操作して規則性を発見する `LAB` を追加しています。

## シミュレーションLAB（全9単元）

LAB一覧から、9単元すべてのシミュレーターを開けます。てこLABと月と太陽LABは専用実装、その他7単元は共通エンジンと単元別ファイルを使う条件操作型シミュレーターです。いずれも、条件を変えると結果がその場で変化します。

### 専用実装

- **てこLAB**：支点・左右のおもり・位置を操作し、傾きと「おもりの数 × 距離」を比べます。
- **月と太陽LAB**：月の位置を動かし、宇宙から見た位置関係と地球から見える月の形を同時に比べます。

### 共通の条件操作型LAB

- **燃焼LAB**：空気の通り道、酸素量、容器の大きさを変え、炎と燃焼時間を比べます。
- **水溶液LAB**：水溶液と調べ方を選び、リトマス紙・蒸発・気体・金属の変化を比べます。
- **電気LAB**：電池の数、器具、スイッチ、蓄電量を変え、光・運動・熱への変換を見ます。
- **植物LAB**：光・水・葉の枚数・葉をおおう割合を変え、水の移動や蒸散を見ます。
- **人の体LAB**：運動の強さ、追いかける物質、食後の養分を変え、呼吸・心拍・血液の流れを見ます。
- **生物と環境LAB**：植物、昆虫、小動物、鳥、水の量を変え、食べる関係の変化を見ます。
- **大地LAB**：水の速さ、運ばれる土砂、火山灰や地震を変え、地層のでき方を見ます。

各LABには、条件操作、即時結果、短い説明、モデル化している部分の注記があります。実際の薬品や実験器具を使う活動では、必ず先生の指示に従います。

## 共通の探究機能

- 順番を強制しない「予想・記録・比較・考察」パネル
- 現在の条件・結果を1操作で保存
- 同じLABの直近3実験を並べて比較
- LABに応じたSVGグラフを自動生成
- `LABノート` に日時、単元、シミュレーター、予想、条件、結果、グラフ用数値、考察を保存
- 保存先は既存問題記録と分離した `rikaLab6.notebook.v1`
- LAB本体は入口を開くまで読み込まず、選んだシミュレーターだけを遅延読み込み

## 特徴

- タブレットで押しやすいレスポンシブUI
- 条件・記録・安全などをカードで分類する実験準備問題
- 結果から「言えること」と「まだ言えないこと」を区別する考察問題
- 進捗、初回正解、間違えた条件カードを `localStorage` に保存
- LABの予想・条件・結果・比較用数値・考察を `localStorage` に保存
- 効果音はWeb Audio APIで端末内生成（初期設定はオフ）
- 外部API、APIキー、サーバー、データベース、外部フォント不使用
- GitHub Pagesでそのまま公開可能

## 設計参考と科学モデル

- [All-Science Sims](https://github.com/listyantidewi1/all-science-sims)：シミュレーター単位の独立構造、直接操作、短い探究課題、遅延読み込みの考え方を調査
- [PhET Interactive Simulations](https://phet.colorado.edu/ja/)：説明を増やさず、操作と反応の対応がすぐ分かる教材UIを参考
- [Concord Consortium STEM Models & Simulations](https://concord.org/our-work/focus-areas/stem-models-simulations/)：見えない現象の可視化、条件操作、データ比較を探究へつなぐ考え方を参考
- [NASA Moon Phases](https://science.nasa.gov/moon/moon-phases/)：月は太陽により常に半分照らされ、地球から見える照らされた部分が公転に伴って変化するモデルを確認

参考プロジェクトのコード、文章、画面デザインはコピーせず、小学6年生の学習内容と既存理科ラボの構造に合わせて独自実装しています。

## LABの実装状況

9単元のLABを実装済みです。LAB本体は入口を開くまで読み込まず、選んだシミュレーターに必要な lab-core.js、共通エンジン、単元別LABスクリプトだけを遅延読み込みします。7単元は共通処理と単元ごとの実装を分け、修正しやすい構成にしています。

## 公開方法

GitHub の `Settings` → `Pages` で、`main` ブランチのルートを公開元に設定します。ビルド処理は不要です。

## 教材データの追加・修正

`units.js` の各単元は `knowledge / preparation / consideration` の3区分です。画面と判定は `app.js` が共通で処理するため、同じ形式でデータを追加できます。

- `knowledge`: 選択肢、正解、説明、対にして覚える知識
- `preparation`: 分類先、条件カード、実験計画の説明
- `consideration`: 観察・実験結果、問い、選択肢、根拠を含む説明

最近の Chrome、Edge、Safari、Firefox。学習記録は利用中のブラウザ内にだけ保存され、別端末とは同期されません。
